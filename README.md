# 🌙 Sistem Informasi Pendistribusian Zakat

Sebuah aplikasi web terintegrasi yang dirancang untuk mendigitalisasi alur pencatatan dan mengoptimalkan pelaporan operasional distribusi zakat. Sistem ini mempermudah amil zakat dalam mengelola data muzakki (pemberi zakat), mustahik (penerima zakat), serta kalkulasi jumlah zakat secara otomatis.

## 💻 Tech Stack
- **Framework:** Laravel 
- **Language:** PHP 8.1
- **Database:** MySQL
- **Frontend:** Bootstrap, HTML, CSS, JavaScript

## ✨ Fitur Utama
- **Manajemen Muzakki & Mustahik:** Pencatatan detail profil dan kategori secara terstruktur.
- **Kalkulasi Otomatis:** Perhitungan distribusi zakat beras dan uang berdasarkan hak masing-masing kategori mustahik.
- **Pelaporan Real-time:** Dashboard yang menampilkan total pengumpulan dan distribusi zakat.
- **Autentikasi:** Sistem login yang aman untuk administrator.
